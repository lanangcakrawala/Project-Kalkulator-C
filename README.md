# Project-Kalkulator-C

# Simple C Calculator - Team Project

Proyek ini adalah aplikasi kalkulator berbasis terminal yang dibangun menggunakan bahasa C sebagai bagian dari tugas kolaborasi pemrograman. Aplikasi ini mencakup fungsi aritmatika dasar dan menggunakan alur kerja GitHub (Branching & Pull Requests).

## 🚀 Fitur Utama
* **Aritmatika Dasar:** Penjumlahan, Pengurangan, Perkalian, dan Pembagian.
* **Validasi Input:** Menangani kesalahan input menu (hanya menerima opsi 1-4).
* **Safety Check:** Proteksi terhadap error pembagian dengan nol (division by zero).
